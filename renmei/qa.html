①

キリスト教・信仰について

聖書や礼拝、お祈りなど、キリスト教の基本について

Q 聖書とは何ですか？ +
A

聖書は、神様の言葉が記された書物です。神様がどのようなお方なのか、私たちをどれほど愛してくださっているのか、そしてイエス・キリストを通して与えられる救いについて教えています。

Q 礼拝とは何ですか？ +
A

礼拝とは、神様を賛美し、祈り、聖書の言葉に耳を傾ける大切な時間です。神様に感謝と喜びをささげ、心を神様に向けるひとときです。

Q お祈りとは何ですか？ +
A

お祈りとは、神様に心を向けて語りかけることです。感謝や喜び、悩みや願いなど、どんなことでも神様にお話しすることができます。特別な言葉や作法は必要ありません。

Q 献金とは何ですか？ +
A

献金とは、神様への感謝の気持ちを表してささげるものです。教会の活動や福音を伝える働きなどのために用いられます。献金は強制ではありませんので、初めて教会に来られる方はご心配なさらないでください。

Q イエス・キリストとはどのようなお方ですか？ +
A

イエス・キリストは、神の御子であり、私たちを罪から救うためにこの世に来られた救い主です。神様の愛を示し、私たちに希望と新しい命を与えてくださるお方です。

Q 神様は本当にいるのですか？ +
A

神様は目で見ることはできませんが、聖書を通してご自身を示し、私たち一人ひとりを愛してくださっています。教会では、神様について一緒に学び、考えていくことができます。

Q クリスチャンとは何ですか？ +
A

クリスチャンとは、イエス・キリストを信じ、神様と共に歩む人のことです。特別な人だけがなれるものではありません。

Q 洗礼（バプテスマ）とは何ですか？ +
A

洗礼とは、イエス・キリストを救い主と信じることを表す大切な儀式です。神様を信じ、新しい歩みを始めることを表しています。

②

教会について

礼拝の雰囲気や服装、持ち物などについて

Q 教会とはどのようなところですか？ +
A

教会は、神様を礼拝し、聖書を学び、互いに支え合いながら歩んでいくところです。初めての方も、どなたでも歓迎いたします。

Q 教会に行くのは初めてですが、大丈夫ですか？ +
A

もちろん大丈夫です。初めての方も安心してお越しください。教会のスタッフやメンバーがご案内いたします。聖書や賛美歌なども、必要に応じてご案内します。

Q クリスチャンでなくても教会に行けますか？ +
A

はい、もちろんです。キリスト教に興味がある方、聖書について知りたい方、教会の雰囲気を感じてみたい方など、どなたでもお越しいただけます。

Q 礼拝には予約が必要ですか？ +
A

基本的に予約は必要ありません。お気軽にお越しください。団体での参加などの場合は、事前にお問い合わせください。

Q 礼拝にはどのような服装で行けばよいですか？ +
A

特別な決まりはありません。普段着など、リラックスできる服装でお越しください。

Q 礼拝にはどのくらい時間がかかりますか？ +
A

礼拝は通常、約〇分です。賛美やお祈り、聖書のお話などを行います。

Q 子どもと一緒に参加できますか？ +
A

はい、お子さまと一緒にご参加いただけます。ご家族で安心してお越しください。

Q 聖書を持っていなくても大丈夫ですか？ +
A

はい、大丈夫です。聖書をお持ちでない方にもご案内できますので、ご安心ください。

Q 礼拝の途中から参加しても大丈夫ですか？ +
A

はい、大丈夫です。途中からでもご参加いただけます。どうぞ遠慮なくお越しください。

③

初めて教会に来られる方へ

ご不安な点やご相談について、安心してお越しいただくために

Q 教会に行ったら、何か勧誘されませんか？ +
A

無理に入会を勧めたり、信仰を強制したりすることはありません。ご自身のペースで教会のことや聖書について知っていただければと思います。

Q キリスト教について何も知らなくても大丈夫ですか？ +
A

もちろんです。聖書やキリスト教について初めて学ぶ方にも、分かりやすくお伝えしています。分からないことがあれば、いつでもお尋ねください。

Q 悩みや心配事があっても相談できますか？ +
A

はい。日々の生活の悩みや心配事など、お話をお聞きします。ご希望があれば、お祈りすることもできます。

Q 一人で教会に行っても大丈夫ですか？ +
A

はい、お一人で来られる方もいらっしゃいます。初めての方も安心してお越しいただけるよう、心を込めてお迎えいたします。

Q 教会に入会しなければいけませんか？ +
A

いいえ、その必要はありません。まずは礼拝に参加したり、教会の雰囲気を感じたりするところから始めていただけます。
